# Magnet Earbud Recovery

> 一个用于指导无线耳机掉入厕所、便池、地漏或浅层排水口后，进行定位、磁吸捞取、清洁、干燥与功能检测的 Codex 生活小技巧 Skill。

## 项目简介

无线耳机体积小、表面光滑，掉入潮湿、狭窄或光线不足的排水开口后，往往难以直接拾取。盲目伸手、反复捅探或误触冲水，还可能将耳机推向更深处。

`magnet-earbud-recovery` 将一次真实的耳机捞取经验整理为可重复使用的决策流程：

1. 先停止冲水并封锁使用现场。
2. 用手电筒判断耳机所在位置和可能的滑动路径。
3. 将小磁铁牢固安装在晾衣杆或其他可控长杆的低端。
4. 沿推测路径小幅度扫动，通过磁吸感、碰击声或重量变化判断是否吸附成功。
5. 在多次失败或位置无法判断时及时停止，避免问题进一步扩大。
6. 捞出后，根据耳机型号和厂商要求进行清洁、干燥与功能检测。

该 Skill 不是管道维修教程，也不鼓励用户进入下水道或拆解固定管路。它的目标是在物品仍处于室内开口附近、能够通过可控工具触及的前提下，帮助用户作出更有条理、更克制的处理决策。

## 何时会启用该 Skill

当用户描述以下情况时，Codex 可以选择启用该 Skill：

- 无线耳机掉入厕所、便池、地漏或浅层排水口。
- 希望使用小磁铁、晾衣杆或长杆捞取小型磁性物品。
- 手电筒在最低处没有照到耳机，需要判断它是否沿斜面滑向左下方或更深处。
- 需要判断磁铁是否已经吸附耳机，以及如何缓慢提起。
- 反复尝试仍无磁吸感，需要决定是否放弃自行捞取。
- 耳机接触污水后，需要了解清洁、干燥、蓝牙连接和声音检测顺序。

也可以显式调用：

```text
使用 $magnet-earbud-recovery 帮我定位、捞取并处理掉入厕所或排水口的耳机。
```

## 不适用的情况

出现以下情况时，应停止自行捞取，并联系物业、管道师傅或设备厂商：

- 耳机已经越过存水弯，或滑入无法看见和安全触及的深层管道。
- 需要进入井口、下水道或其他封闭空间。
- 需要拆解固定管路，或使用带电工具接近潮湿开口。
- 现场存在异常气味、有害气体、飞溅风险或无法保持安全站立姿势。
- 长杆、磁铁或固定结构可能脱落或卡住。
- 捞出的耳机出现发热、变形、漏液、异味或其他电池异常。

## 核心原则

### 1. 先防止现场状况继续恶化

捞取开始前必须停止冲水，并明确告知室友或其他同住者暂时不能使用该厕所。如果中途有人要使用，应立即制止并请其前往其他厕所。

这不仅是为了防止耳机被冲得更深，也是为了避免水流使长杆、磁铁或使用者失去控制。

### 2. 区分观察结果与位置推测

用手电筒看到的位置是观察结果；根据斜面、凹槽和排水方向判断耳机可能滑向左下方或更深处，则属于推测。引导过程中应清楚区分两者，避免将推测当成确定事实。

### 3. 确保磁铁与长杆始终可控

磁铁不应只用胶水粘贴。除了粘合，还应使用绑扎、夹持或系绳作为第二道保险，避免磁铁也掉入排水口。正式尝试前，应在开口外测试磁铁的吸附能力和湿水后的固定强度。

### 4. 有限尝试，不进行无止境的盲探

每次尝试后都要重新用手电筒观察，根据新的位置信息调整深度和方向。如果连续尝试几遍仍没有磁吸感，或已经无法判断耳机位置，就应停止自行捞取。

## 捞出后的处理顺序

捞出耳机不代表处理已经结束。耳机可能同时面临污染与进水风险，建议按以下顺序处理：

1. 不要立即佩戴、充电或连接蓝牙。
2. 查看该型号的防水等级和厂商清洁说明。
3. 采用与设备兼容的方法清洁外壳，避免水或清洁液进入扬声器孔、麦克风孔和充电触点。
4. 不把“堵住孔洞后在水龙头下冲洗”作为所有耳机都适用的通用方法；只在厂商明确允许时使用流水冲洗。
5. 吸干表面水分，将孔洞朝下，放置在通风、干燥的环境中。
6. 不使用热风吹风机、压缩空气或高温烘烤。如果厂商允许冷风，也应隔着一定距离轻吹，防止把水分推入更深处。
7. 完全干燥后，先检查是否出现发热、变形、异味或其他异常。
8. 确认无异常后，再测试蓝牙连接、声音、麦克风和充电功能。

如果耳机无法连接蓝牙、连接后没有声音，或者出现持续异常，应联系厂商进行检修，或考虑购买对应型号的单只耳机配件。

## 设计理念

这个项目不试图用一套固定动作覆盖所有管道结构。它更强调三个能够迁移到类似场景的能力：

- **观察**：用光线和多角度观察建立对现场结构的基本判断。
- **推理**：根据斜面、凹槽和排水方向推测小型物体的滑动路径。
- **克制**：通过明确的尝试次数和停止条件，避免小问题在盲目操作中演变为更难处理的问题。
